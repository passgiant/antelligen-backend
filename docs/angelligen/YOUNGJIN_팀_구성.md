# 👥 멀티 에이전트 기능 확장 및 역할 분담

---

## 🧠 김영진 — 데이터 소스 확장 / 신뢰도 가중치 / 에이전트 통합

### 📡 데이터 확장

- 뉴스 에이전트 **8개 소스 제한 해제**
- **미국 주식 뉴스까지 확장**
- 공시·재무 에이전트에 **해외 데이터 추가**
- 재무 에이전트 **잠정 실적 등 최신 데이터 반영**

---

### 🎯 출처 신뢰도 가중치 (4단계)

| 등급 | 기준                                       |
| ---- | ------------------------------------------ |
| 상   | DART 공시, 1군 투자은행 공식 리포트 (미국) |
| 중   | 2군 경제 전문지, 월가 애널리스트           |
| 중하 | 1군 투자은행 공식 리포트 (한국)            |
| 하   | SNS, 일반 뉴스, 투자 커뮤니티              |

---

### ⚙️ 가중치 로직

- 섹터별 예외 처리
  - 엔터·게임 등 → **SNS 영향력 높은 산업**
  - → SNS 가중치 상향 적용

- 메인 에이전트 종합 시그널 계산 시
  - **confidence 산정에 직접 반영**

---

### 🔗 에이전트 통합

- 거시 경제 에이전트 + 감정 분석 에이전트
  → 메인 에이전트 **종합 시그널로 통합**
