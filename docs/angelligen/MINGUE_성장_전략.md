# 📈 성장 전략

---

## 1. 시장 진입 전략

### 🎯 목표 고객

#### 1차 — 개인 투자자

한국 및 미국 주식 투자자 중  
“이 종목이 오늘 왜 떨어졌지?”를 검색하는 사용자

- 여러 뉴스와 데이터를 직접 조합해야 하는 불편 존재
- → 차트 + 사건 + 원인 분석을 한 화면에서 제공

#### 2차 — 데이터 기반 판단을 원하는 사용자

- 신입 애널리스트
- 투자 콘텐츠 크리에이터
- 학생 투자 동아리

> 기존 문제

- 블룸버그 등은 월 200만 원 이상
- 한국 데이터는 상대적으로 약함

→ **한국 공시 중심 + 합리적인 가격 전략**

---

### 🌐 진입 채널 — 웹 중심 전략

- 초기: **웹사이트 기반 서비스**
- 이후: PWA 형태 (홈 화면 추가)
- 최종: 사용자 확보 후 **모바일 앱 출시**

---

### 🚀 사용자 확보 전략

#### 1. 검색 유입 (SEO)

- 종목별 “왜 떨어졌나” 페이지 자동 생성
- 자연 검색 트래픽 확보

#### 2. 커뮤니티

- 디스코드
- 네이버 종목 카페
- 주식 갤러리

→ 초기 사용자 시드 확보

#### 3. 인플루언서

- 투자 유튜버 협업
- 분석 데이터 콘텐츠 활용
- 크리에이터용 도구 제공

---

## 2. 핵심 지표 (KPI)

### 📊 사용량 (Engagement)

- MAU (월 사용자 수)
- 7일 재방문율
- 체류 시간
- 클릭률

**목표**

- 초기: 30~50명
- 확장: 10,000명
- 재방문율: 30% → 40%

---

### 🎯 품질 (Quality)

- 사용자 만족도 (5점 기준)
- 자신 있는 분석 비율
- 출처 클릭률
- 검증된 사례 수

**목표**

- 만족도: 4.0 → 4.5
- 자신 있는 답변: 30% → 45%

---

### ⚡ 비용 (Efficiency)

- 캐시 재사용률
- 응답 속도
- 종목당 분석 비용

**목표**

- 응답 속도: 8초 → 3초
- 비용: 200원 → 50원

---

### 💰 사업성 (Business)

- 회원가입 전환율
- 유료 전환율
- NPS (추천 의향)
- 월 매출

**목표**

- 유료 전환율: 3%
- 월 매출: 100만 원 (1차 마일스톤)

---

## 3. 서비스 확장 전략

---

### 🌍 방향 1 — 시장 및 자산 확장

**핵심: 분석 엔진 유지 + 데이터 확장**

#### 🌎 시장 확장

- 일본 (니케이)
- 유럽 (영국, 독일, 프랑스)
- 신흥국 (인도)

#### 💰 자산 확장

- 암호화폐
- 원자재 (금, 원유)
- 채권
- 리츠 (부동산)

#### 📡 대안 데이터

- 커뮤니티 데이터 (종토방, 블라인드)
- 위성 데이터
- 카드 소비 데이터

---

### 🧩 방향 2 — 기능 확장 (Same User)

- 포트폴리오 분석
- 실시간 알림
- 과거 검증 (백테스트)
- 일일 리포트
- 주간 인사이트
- 종목 비교
- 시나리오 분석

---

### 🧠 방향 3 — 분석 모듈 확장

- 감정 분석 (뉴스 + SNS)
- 실적 발표 분석
- 거시경제 예측
- 내부자 거래 분석
- 종목 비교 분석
- 리스크 분석

> 구조적 장점  
> → **모듈 추가 비용이 점점 감소**

---

### 💼 방향 4 — 수익 모델 확장

| 모델          | 대상              | 가격                |
| ------------- | ----------------- | ------------------- |
| 무료 플랜     | 신규 사용자       | 0원                 |
| 개인 프로     | 개인 투자자       | 월 9,900원          |
| 개인 프리미엄 | 인플루언서/동아리 | 월 29,000원         |
| API 서비스    | 핀테크/증권 앱    | 호출당 과금         |
| 기업 전용     | 증권사/헤지펀드   | 월 500만~5,000만 원 |
| 라이선스      | 증권사 앱         | 매출 분배           |
