# 1. /settings/watchlist — 관심종목 관리

## 개요

로그인한 사용자가 관심 있는 종목을 직접 선택·해제하는 설정 페이지입니다.
여기서 등록한 종목은 뉴스(`/news`)와 유튜브(`/youtube`) 페이지의 콘텐츠를 개인화하는 데 직접 사용됩니다.

## 인증 방식

- Redis 세션 기반 인증 — 쿠키(`user_token`) 또는 `Authorization: Bearer` 헤더 둘 다 지원
- 로그인한 사용자에게만 내비게이션 메뉴에 노출
- 세션 미존재 시 `401` 반환

## UI 구성

테마 그룹별로 종목 버튼이 나열되며, 버튼을 클릭해 관심종목을 토글합니다.

- **[ 반도체 ]** 삼성전자, SK하이닉스 ...
- **[ 자동차 ]** 현대차, 기아 ...

- **선택된 종목:** 채워진 버튼 (검정/흰색)
- **미선택 종목:** 빈 버튼
- **현재 선택 개수 표시**

## API 구성 (`/api/v1/users/me/watchlist`)

| Method | Endpoint                     | 설명                                               |
| ------ | ---------------------------- | -------------------------------------------------- |
| GET    | `/me/watchlist`              | 내 관심종목 전체 조회 (종목코드 + 종목명 + 테마명) |
| POST   | `/me/watchlist`              | 종목 추가                                          |
| PUT    | `/me/watchlist/{stock_code}` | 종목 교체                                          |
| DELETE | `/me/watchlist/{stock_code}` | 종목 삭제 (204)                                    |

## 핵심 연동 — 뉴스 페이지 개인화 (`/news`)

관심종목 등록 후 뉴스 페이지를 열면, 등록한 종목명으로 DB 뉴스를 필터링하여 맞춤 피드를 반환합니다.

**동작 방식:**

- 사용자 세션 → 관심종목 목록 조회
  - ▶ 종목별 `stock_name`으로 뉴스 DB 제목 검색 (종목당 최대 10건)
    - ▶ URL 기준 중복 제거
      - ▶ 최신순 정렬 후 반환

> **참고:** 관심종목 미등록 시 전체 최신 뉴스 100건을 기본으로 표시 (`has_watchlist: false`)

## 핵심 연동 — 유튜브 페이지 개인화 (`/youtube`)

관심종목 등록 후 유튜브 페이지를 열면, 등록한 종목명을 YouTube 검색 키워드로 사용하여 관련 영상 피드를 구성합니다.

**동작 방식:**

- 사용자 세션 → 관심종목 목록 조회
  - ▶ 종목명 최대 5개를 키워드로 YouTube 병렬 검색
    - ▶ 중복 영상 제거
      - ▶ 최신순 정렬 → 페이지당 9개 반환

> **참고:** 관심종목 미등록 시 (또는 비로그인) 기본 키워드로 대체
> ("주식 경제 투자", "코스피 증시 분석", "미국 주식 투자", "반도체 주식", "성장주 가치주")

## 요약

| 페이지     | 관심종목 없을 때                 | 관심종목 있을 때                    |
| ---------- | -------------------------------- | ----------------------------------- |
| `/news`    | 전체 최신 뉴스 100건             | 등록 종목명으로 필터링된 맞춤 뉴스  |
| `/youtube` | 일반 주식 투자 키워드 5개로 검색 | 관심종목명 최대 5개를 키워드로 검색 |

# 2. /smart-money — 스마트머니

## 개요

한국 주식시장에서 외국인·기관·개인 투자자가 어떤 종목을 얼마나 사고팔았는지 보여주는 페이지입니다.
KRX(한국거래소)에서 매 영업일 자동 수집한 데이터를 기반으로, 누가 어디에 돈을 넣고 있는지 한눈에 파악할 수 있습니다.

## 데이터 수집 스케줄러

**매 영업일 16:30 KST** — 장 마감 30분 후 자동 수집

- KRX → KOSPI + KOSDAQ 전 종목
  - ▶ 외국인 / 기관합계 / 개인 투자자별
    - ▶ 종목별 순매수거래량 + 순매수거래대금 → DB 저장

## UI 구성 — 3개 섹션

### ① 스마트머니 집중 매수 종목

외국인과 기관이 동시에 순매수한 종목만 교집합으로 추출해 카드 형태로 표시합니다.

- **기간 드롭다운:** 최근 3일 / 5일 / 10일 선택 가능
- **각 카드 표시 정보:**
  - 종목명 + 종목코드
  - 외국인 순매수 금액 (억 원)
  - 기관 순매수 금액 (억 원)
  - 집중도 점수 (0~100) + 시각적 게이지 바

**집중도 점수 계산:**

- 외국인 점수 = 내 순매수 ÷ 전체 최대값 (0~1 정규화)
- 기관 점수 = 내 순매수 ÷ 전체 최대값 (0~1 정규화)
- 집중도 점수 = (외국인 점수 + 기관 점수) ÷ 2 × 100

### ② 해외 스마트머니 집중 매수 종목 (미국)

19명 글로벌 유명 투자자 중 동시에 신규편입·비중확대한 미국 주식 랭킹을 카드로 표시합니다.

- SEC 13F 분기 공시 기준일 표시
- **각 카드 표시 정보:**
  - 종목명 + 티커
  - 총 매수 시장가치 (달러, M/B 단위)
  - 매수 투자자 수 (19명 중 몇 명이 샀는지) + 비율 게이지 바
  - 해당 종목을 매수한 투자자 이름 태그

### ③ 투자자별 순매수 랭킹 탭

외국인 / 기관 / 개인 탭을 클릭하면 해당 투자자 유형의 당일 순매수 상위 종목 테이블이 표시됩니다.

- **테이블 컬럼:** 순위 / 종목명 / 종목코드 / 순매수금액 / 순매수수량
- **행 클릭 시:** 해당 종목의 최근 30일 투자자별 추이 차트 펼침
  - X축: 날짜
  - Y축: 순매수금액 (억 원)
  - 라인 3개: 외국인(파랑) / 기관(초록) / 개인(노랑)

> **참고:** 추이 차트 데이터는 Redis TTL 10분 캐싱 적용

## API 구성

| Endpoint                                               | 설명                  |
| ------------------------------------------------------ | --------------------- |
| GET `/smart-money/investor-flow?investor_type=FOREIGN` | 투자자별 순매수 랭킹  |
| GET `/smart-money/concentrated?days=5`                 | 집중 매수 종목 (국내) |
| GET `/smart-money/us-concentrated`                     | 집중 매수 종목 (미국) |
| GET `/smart-money/trend/{stock_code}?days=30`          | 종목별 투자자 추이    |
